## 💡 How to Use LiemAI 2.0

LiemAI 2.0 is built for fluid, terminal-first workflows. Below is a breakdown of its workflow and core features.

---

### 1. Initialization & Session Modes
When starting LiemAI via `python v2.0/main.py`:
* **User Identification:** Enter your name so LiemAI can personalize dialogue.
* **License Verification:** Free users can test within a trial quota. Enter an authorized key when prompted to unlock unlimited interactions.
* **Session Persistence:**
  * Type `y` (**Persistent Mode**): LiemAI creates or resumes `session_<your_name>.json`. Conversation state automatically saves after every exchange.
  * Type `n` (**Temporary Mode**): Conversations remain strictly in RAM and discard upon exit.

---

### 2. Modern Terminal Interface & Streaming
* **Multiline Input:** Draft multi-line queries, code snippets, or logs freely without premature triggering.
* **Real-time SSE Streaming:** Tokens render as they generate, cutting out idle waiting periods.
* **Rich Markdown Engine:** Responses render with syntax-highlighted code blocks, structured tables, and clear visual blockquotes.

---

### 3. Integrated Slash Commands

Execute these commands directly inside the prompt input:

* **Inspect Local Files (`/file`)**
  * *Syntax:* `/file <path_to_file> [instructions]`
  * *Example:* `/file src/engine.py find why this loop triggers an IndexError`
  * *Behavior:* Reads the target file directly from disk, attaches its raw contents to your query, and streams the analysis.
* **Export Chat Context (`/save`)**
  * *Syntax:* `/save [filename.json]`
  * *Behavior:* Dumps the active conversation history into a structured JSON file.
* **Restore Chat Context (`/load`)**
  * *Syntax:* `/load <filename.json>`
  * *Behavior:* Loads a previously saved JSON session directly into active context.
* **Clear Working Memory (`/reset`)**
  * *Syntax:* `/reset`
  * *Behavior:* Flushes context memory to begin a clean conversation without restarting the process.
* **Safe Exit (`esc`)**
  * *Syntax:* Type `esc` and press Enter to cleanly close the CLI session.
